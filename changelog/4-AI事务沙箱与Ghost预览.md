# CADX AI 事务沙箱与 Ghost 预览变更记录

> 更新日期：2026-08-04
> 版本：0.4.0

本次更新补齐 AI Native 架构中的写入安全边界：AI 方案不再只是文本命令列表，而是先形成经过真实几何内核验证、绑定文档版本、可视化且可审计的只读事务预览；领域 AI 意图也必须经过请求级工具白名单和同一事务管线。

## 1. CoW 事务沙箱

- `DocumentSession` 新增不可由外部构造的 `TransactionPreview`，保存基础 revision、暂存文档、求值场景、创建的特征 ID 和结构化差异。
- 预览在克隆文档上应用完整命令批次并调用当前 `CadKernel`，不改变活动文档、场景、dirty 状态或撤销/重做历史。
- `DocumentDiff` 按稳定 ID 报告新增、修改、删除特征，以及发生变化的装配记录和领域数据命名空间。
- 批准时消费已经验证的预览并生成一个撤销 revision；基础 revision 不一致时以 `StalePreview` 失败关闭。

## 2. AI 并发控制

- 每个异步 AI 请求分配单调唯一的 request ID，记录上下文 document revision，并持有 Tokio abort handle。
- 用户可通过规划状态旁的取消按钮或 Escape 立即终止 provider future；成功编辑、撤销/重做、新建或打开文档也会主动取消已经过期的请求，不再等待网络超时。
- 只有仍被追踪的 request ID 才能完成。即使已取消任务的响应已经进入 channel，也不能清除或覆盖后续请求；LLM 返回时若文档已经变化，方案仍会在进入沙箱前直接拒绝。
- CoreBus 新增预览准备与放弃事件，并沿用统一的事务开始、提交和拒绝事件。

## 3. Ghost 视口

- 新增独立的 WGPU 透明实体与参考线渲染管线，禁用深度写入并启用 alpha blending。
- 新增和修改后的暂存几何以青色显示；即将删除的已提交几何以红色显示。
- Ghost 几何不参与拾取、测量、分析或导出，活动场景仍是唯一工程数据源。
- AI 审批面板显示命令清单、特征 ID/名称差异、装配和领域数据变化；放弃、撤销/重做、新建/打开或其他成功编辑会清除预览。

## 4. 多候选设计比较

- AI 合约支持一个主方案和最多两个独立备选方案；每个方案都是基于同一已提交文档的完整命令批次，不能依赖其他候选的结果。
- 每个候选分别经过 CoW 文档应用和真实内核求值，失败候选会被排除，不会产生部分几何。
- `cadx-analysis` 从已提交场景和候选场景计算实体数、三角面数、体积、表面积、可用质量与质心位移变化；LLM 不能填写这些工程指标。
- 支持干涉分析的内核会直接分析候选的暂存文档，且不改变活动 session 或历史。
- 审批面板可切换最多三个候选及对应 Ghost 场景，显示本地工程证据；批准仅提交当前候选，其余候选显式发布放弃事件。

## 5. 领域 AI 工具路由

- `DomainAiRequest` 携带当前领域的请求级工具白名单；Provider 只能从白名单中恰好选择一个工具，不能直接返回核心 CAD 命令。
- `ToolRegistry` 注册领域包时原子校验工具 ID、AI 工具 ID 及 `executable_tool_id` 映射；重复 ID 或未知可执行工具会拒绝整包注册，不留下半套索引。
- 领域面板字段会生成严格 JSON Schema，覆盖字符串、枚举、整数、数值、布尔、实体引用、单位、默认值和必填项；返回参数在调用领域包前再次拒绝未知字段、错误类型和无效取值。
- 桌面端把已验证的领域动作转换为 `ModelCommand` 与领域元数据，在同一 CoW 预览中完成内核求值；审批前不写入文档，审批后才执行延迟的非几何动作和产物更新。内置 MCAD、AEC、ECAD 工具均绑定到明确的可执行工具，MCAD 草图入口和 ECAD 布线入口同步纳入路由。

## 6. Provider 网关兼容

- 自定义 OpenAI-compatible endpoint 使用结构化 URL 解析，并统一补齐 base path 尾斜杠，避免 SDK 将无尾斜杠的 `/v1` 当作文件段替换成 `/chat/completions`。
- endpoint 只接受 HTTP(S) base URL，保留 query 参数并拒绝 fragment；新增 `/v1`、多级路径、query、非法 scheme 和 fragment 回归测试。
- Provider 非 JSON HTML 页面会转换为可操作的短错误，其他外部错误也会折叠空白并限制长度，避免认证页面或代理响应充满 AI 对话区。

## 7. 动态空间与焦点上下文

- 通用 AI 请求改为对当前 revision 收集有界类型化上下文：选择与持久拓扑所有者优先，其次是提示词名称/ID 命中、上下游各两跳依赖图、相对选择焦点或视口目标的 AABB 邻域，最后才使用最近特征回退。
- 默认发送最多 32 个完整特征摘要和 16 个空间实体，硬上限分别为 64 和 32；选择边、领域 Schema、场景逐零件详情均有独立边界和显式遗漏状态。
- Provider 不再序列化完整 `CadDocument`。只有检索到的特征携带完整参数；STEP 内嵌源内容继续脱敏，领域数据仅发送命名空间计数，相关装配最多 8 个且每个最多 32 个 occurrence，并保留必要祖先、definition 和 mate 端点。
- 干涉分析保留完整聚合计数，但候选特征 ID 和 pair 明细按上下文相关性排序并分别限制为 64 和 32 条，同时报告遗漏数。
- 新增大文档参数隔离、选择/提示命中预算优先级、遗漏计数、相关装配子图、干涉明细边界和 STEP 源脱敏回归测试。

## 8. 回归覆盖

- 新增 CoW 零突变、差异分类、过期预览拒绝、候选干涉只读分析、场景指标比较、三候选上限、领域工具 Schema/参数校验、单 revision 提交、CoreBus 预览事件、Ghost 独立缓冲区，以及 provider 取消、迟到响应隔离和修订变化自动取消测试。
- 中英文界面新增预览状态、候选切换、结构差异、工程证据、过期上下文、缺失预览和规划取消提示。
