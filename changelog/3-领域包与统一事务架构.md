# CADX 领域包与统一事务架构变更记录

> 更新日期：2026-08-03
> 版本：0.3.0

本次更新将 CADX 扩展为共享同一文档、几何内核和事务管线的多领域 2D/3D CAD 工作台，新增 MCAD、AEC/BIM 和 ECAD 领域包，并将桌面交互与 AI 意图统一接入可验证、可撤销的命令流。

## 1. 领域包架构

- 新增几何中立的 `cadx-domain-api` SPI，定义领域包清单、工具、Schema 表单、求解器、着色器、AI 工具、诊断、产物和导出校验契约。
- 新增 `DomainRegistry`，支持领域包注册、启用/禁用、Schema 参数验证、工具执行和自然语言路由。
- 领域包不依赖 egui、`cadx-core` 或 Truck；它们返回中立的业务动作、诊断和产物，由桌面组合根转换为核心命令。
- `CadDocument` 新增有边界校验的命名空间 `domain_data`，使 BIM、ECAD 等不透明领域数据参与保存、事务回滚和撤销/重做，同时不影响几何求值。

## 2. MCAD 能力

- 新增特征依赖校验、脏标记传播、确定性重建顺序以及装配 mate 校验和位姿建议。
- 新增 GB/T、ISO 和 ASME 工程图标准、注释检查、标准件目录、可制造性检查和稳定分组的 BOM。
- MCAD 聚合包暴露草图、拉伸、倒角/圆角、装配、标准、DFM 和 BOM 工具，并提供对应的表单和 AI 意图路由。

## 3. AEC/BIM 能力

- 新增经验证的 BIM 项目、楼层、分类构件、属性、墙/板规格、明细表和工程量统计模型。
- 新增基于空间包围的确定性 BIM 碰撞检查，以及经验证、可复现的 IFC4/IFC4X3 STEP Physical File 导出。
- AEC 领域工具可在同一事务中创建墙体/楼板几何并写入 BIM 身份与属性，同时提供明细、工程量、碰撞和 IFC 入口。

## 4. ECAD 能力

- 新增原理图网表及引脚归属校验，以及电路板轮廓、铜层/介质层堆叠、元件、焊盘、过孔、走线、禁布区和设计规则模型。
- 新增确定性正交布线与差分对建议，支持元件、走线、板边、铜间距、焊盘、钻孔、过孔、层和网络的 DRC。
- 新增 Gerber 铜层/板框、Excellon 钻孔文件与 STEP 板框导出；板框和元件可映射为普通核心实体，并保留 ECAD 领域元数据。

## 5. 统一事务与 AI

- `cadx-app` 新增 `CoreBus`，对 UI、AI、领域包和导入操作标记来源，支持流式命令缓冲、原子提交、事件分发和有界事件日志。
- 新增 AI 上下文收集器、领域工具索引和显式 `IntentDiff`。自然语言请求会先由当前领域包路由，用户确认后再进入同一事务管线。
- 通用 AI 计划和领域工具都不能绕过 `DocumentSession` 和几何内核验证，完整批次仅在成功求值后生成一次可撤销修订。

## 6. 桌面工作台与验证

- 顶部新增领域包切换与运行时启停，工具区根据 MCAD、AEC 或 ECAD 展示对应的 Schema 表单、分析和导出操作。
- 桌面端将领域几何动作和命名空间元数据翻译为同一核心事务，并在新建、打开、撤销和重做后同步领域状态。
- 补充中英文领域工具、面板、诊断和状态文案，并新增注册表、事务流、文档历史、MCAD、AEC/IFC、ECAD 布线/DRC/导出等回归测试。
